# The Dolomites — 6–11 กันยายน 2026

แผนที่ทริปสำหรับกลุ่ม 8 คน 2 คัน ฐานที่พัก **Hofer Hof, Feldthurns (Velturno)**
UI ภาษาไทย · ชื่อสถานที่คงภาษาอิตาลี/เยอรมันไว้ให้ตรงกับป้ายถนนและ Google Maps

## เว็บมีอะไรบ้าง

1. **ที่พัก** — Temblhof (6 ก.ย.) และ Hofer Hof (7–11 ก.ย.) พร้อมวันที่ เวลาเช็กอิน/เอาต์ ที่อยู่ และเบอร์ติดต่อของที่พัก
2. **ที่เที่ยวและเส้นทางเดินป่า** — 15 จุด พร้อมระยะทาง ความสูงที่ไต่ ความยาก เวลา และช่วงเวลาที่ดีที่สุด
3. **เส้นทางขับรถ** — จาก Hofer Hof ไปทุกจุด ตามถนนจริง พร้อมระยะทางและเวลาจริง + ปุ่มเปิด Google Maps ทุกหมุด
4. **ชั้นกฎการเข้าถึงปี 2026** — 13 เรื่อง ระบุว่าอะไรถูกจำกัด เมื่อไร ราคาเท่าไร ต้องจองอะไรล่วงหน้า พร้อมลิงก์เว็บจองทางการ
5. **ชั้นเทียบฐานที่พัก** — เทียบเวลาขับรถจาก Hofer Hof กับ Ortisei (Val Gardena), Cortina d'Ampezzo และ Dobbiaco

## สถานะการตรวจสอบ

ข้อมูลกฎปี 2026 ทุกข้อตรวจสอบกับแหล่งทางการเมื่อ **3 สิงหาคม 2026** — เทศบาล อุทยาน
ผู้ให้บริการกระเช้า และพอร์ทัลจองที่จอดรถ ทุกบรรทัดในเว็บมีป้ายบอกสถานะ:

| ป้าย | ความหมาย |
|---|---|
| ยืนยันแล้ว | ยืนยันจากแหล่งทางการปี 2026 |
| ยืนยันบางส่วน | มีแหล่งทางการ แต่ไม่ระบุปี 2026 ชัด หรือข้อมูลขัดกันเอง |
| แก้จากไกด์เดิม | ไกด์เดิมระบุผิด — ตัวเลขในเว็บคือค่าที่ถูกต้อง |
| ยังไม่ยืนยัน | หาแหล่งทางการยืนยันไม่ได้ — อย่าเชื่อเป็นข้อเท็จจริง |

**ต้องเช็กซ้ำก่อนเดินทาง:** สถานะ ZTL ของ Passo Gardena, แผงกั้นถนน Santa Maddalena,
วันสิ้นสุดฤดูกาลจองที่จอด Alpe di Siusi และสถานะงานถนน SR48

## เรื่องความเป็นส่วนตัว

เว็บนี้เป็นสาธารณะ — **ไม่มีข้อมูลการจองส่วนตัวใด ๆ** ไม่มีเลขยืนยันการจอง PIN
เลขบัตรเครดิต เลขตั๋ว ชื่อผู้จอง หรือเบอร์/อีเมลของผู้เดินทาง
มีเฉพาะที่อยู่และเบอร์ติดต่อของที่พักซึ่งเป็นข้อมูลธุรกิจสาธารณะอยู่แล้ว

## โครงสร้างไฟล์

```
index.html            หน้าเดียว ไม่มี build step
assets/leaflet.js     Leaflet 1.9.4 (เก็บไว้ในเครื่อง ไม่พึ่ง CDN)
assets/leaflet.css
assets/images/        ไอคอนของ Leaflet
assets/data.js        ข้อมูลสถานที่ + กฎ 2026 + ฐานที่พักทางเลือก
assets/routes.js      เส้นทางขับรถที่คำนวณไว้ล่วงหน้า (ไม่เรียก API ตอนเปิดหน้า)
assets/app.js         ตรรกะแผนที่และ UI
assets/style.css
build_routes.py       สคริปต์สร้าง routes.json จาก OSRM (รันตอน build เท่านั้น)
routes.json           ผลลัพธ์ดิบจาก build_routes.py
screenshots/          ภาพตรวจสอบหน้าเว็บ
```

```bash
python3 build_routes.py            # เขียน routes.json
```
